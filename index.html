O catálogo inicial de vídeos públicos identificados está gravado neste HTML. A classificação de mais vistos não foi integralmente verificada. Você pode importar mais IDs (até 200 por canal) sem API; os novos itens ficam salvos no navegador usado.

Importar catálogo de vídeos (pais)

Cole um JSON no formato {"Mundo Bita":["cjONzZPJONc"]}. Máximo de 200 IDs por canal. Apenas os 22 nomes aprovados são aceitos; os vídeos devem pertencer aos canais indicados.

A chave fica somente neste navegador. Em um site público, ela deve ser restringida por HTTP referrer no Google Cloud para o domínio do seu GitHub Pages. A chave pode ser vista por quem acessa o site; não use uma chave sem restrições.

Como obter chave API

Google Cloud Console → APIs e Serviços → Ativar YouTube Data API v3 → Credenciais → Criar chave. Em Restrições de aplicativo, use Sites (HTTP referrers), incluindo seu domínio github.io; em Restrições de API, selecione YouTube Data API v3. Pesquisas e consultas consomem cota da API.
